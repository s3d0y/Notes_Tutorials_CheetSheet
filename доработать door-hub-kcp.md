# Door Hub (DorHub) — КЦП по шаблонам Rocketyze VPM

**Продукт:** Door Hub / DorHub · **Сайт:** https://dorhub.ru/

**Методика и инструкции:** [курс Rocketyze VPM](https://vpm.rocketyze.com/) · шаблоны PDF: [Rocketyze_VPM_all_templates_v.1.3.pdf](https://rocketyze.com/public_resources/Rocketyze_VPM_all_templates_v.1.3.pdf)

---

## Как этот файл связан с `door-hub.md`

| Файл | Что внутри |
|------|------------|
| **`door-hub.md`** | Карта в логике **профиль клиента (работы / боли / выгоды) ↔ карта ценности (продукты, обезболивающие, создатели выгоды) + fit** — удобно для глубокого разбора и проверки соответствия. **Ничего не заменяет.** |
| **`door-hub-kcp.md`** (этот файл) | Те же мысли, но **в точной разметке четырёх листов Rocketyze** из PDF/скринов: главная карта, проблемы/выгоды, барьеры, коммуникация. |

**Порядок работы (типичный):** сначала черновики **лист 2** и **лист 3**, затем сводка **лист 1**, потом **лист 4**. Когда блоки здесь заполнены, можно переносить формулировки в `door-hub.md` в соответствующие разделы B/C/D — так два документа остаются согласованными.
