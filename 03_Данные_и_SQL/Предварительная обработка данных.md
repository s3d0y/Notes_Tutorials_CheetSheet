Предобработка включает в себя, очистку от шумов, работа с Нулл,
удаление дубликатов, нормирование данных (убрать выбросы по договоренности)

Нерелевантные поля:
- Все значения в поле одинаковые
- все значения ошибочные 
- все значения с разным типом данных
- поля с большим количеством пустых - Нул ,НаН , 0

Проверка на полноту: 

проверить количество пустых значений в каждом поле таблицы и выяснить причины их появления. Далее сообщаем заказчику и так же говорим являются ли эти пропуски критичными

варианты обработки
- заполнить пропуски средним по полю
- заполнить пропуски максимум по полю
- удалить пропуски

Проверка на дубликаты:

Один из вариантов - группируем по ID смотрим то что больше одного

метод обработки зависит от типа дублирования:
- полные ( вся строка повторяется). Чаще всего из за некорректного запроса. Удаляем.
- Частичная (дубликаты только по части полей) - требуют раскопки, метод зависит от результатов
- только по одному полю (дублируются только по одному полю) - чаще всего решается через агрегирование

Проверка на шумы и выбросы (явные аномалии):

Являются следствием:
- ошибки в данных  (неверные записи, неточные измерения, округления)
-  Наличие шумовых объектов (неверно классифицированные объекты)
- присутствие объектов "других" выборок  (сломался парсер например)

Как обработать:
- заменить на подходящее значение
- исключить из исследования

## Оценка качества данных
Условно "Бизнес оценка"
- Доступность 
- Релевантность
- Своевременность

Условно "Техническая оценка"
- Непротиворечивость
- Однозначность
- Полнота
проверка на NULL
- Взаимосвязанность
- Точность
