### Описание
Добавил плагины. Часть хоткеев работает через них. но где настроить пока не ясно. 
- Hotkey ++
- ShortCuts extender

### Написание текста
%%Сделать перекрестную ссылку на Маркадун Разметку%%

ctrl +1,2,3 - сделать заголовок
ctrl + 0 - убирает заголовок
ctrl + e -  режим "просмотр / редактирование"
ctrl + p - вызов списка фич 
alt + выделение мышью - мультикурсор
ctrl+B - **жирный** или символом ** с двух сторон от текста
ctrl+k - вставить [ссылку](Маркдаун%20разметка.md) 
alt+enter - перейти по ссылке под курсором
Попробовать настроить хоткеи - поискать 
Alt + -/+ - список 
Ctrl + M - ToDo List
ctrl + shist + C - новая заметка из выделенного текста. старый текст вырезается. Рефакторинг 
ctrl + click - открыть в новой вкладке
ctrl+o- последние документы + поиск + создавать файл, если такого нет 
Ctrl + , - настройки
