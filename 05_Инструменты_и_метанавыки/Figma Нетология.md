## 1 урок

Есть онлайн, есть офлайн - [Сайт тут](https://www.figma.com/)

###  Что такое Figma
Программа для работы с векторной графикой, заточенный под интерфейсы. Web, ,банеры, мобильные приложения. 
Коммуникация с командой и общими макетами. 

Полность онлайн. Работает только с интренетом. 

### Интерфейс

Левая верхня панель - инструменты. 
Комментарии видны при включении [значка](Pasted%20image%2020211229120919.png) на панели в верехнем левом углу 

Левая часть:
- список слоев 
- список страниц

Правая часть :
- область со свойствами объектов

Правый верхний  угол окло "Шары"[символ](Pasted%20image%2020211229121349.png) - "презентация" (Аналог F5 PowerPoint ?)


Вкладки:
- Дизайн
- Прототипирование
- Инспект - вид кода. 

Если открывать файл не со своего аккаунта - нельзя корректировать документ. 



### Hot key - [ссылка](https://figma.help/articles/figma-hotkeys-in-russian/)

[Хоткеи в ноушн](https://slashdesigner.notion.site/3997e6ca7e1f42928f8ab677009a580d?v=b43dab876ea948b28c344f497e71720b)

Вставка в начало коррдинат объекта - ctrl+shift+V
Сrl +shift + ?  (Либо на знак вопроса в правом нижнем углу) подсказка с шорткатами (хоткеями) 
Ctlr + \ - открыть/ скрыть интерфейс
С - оставить комментарий. 
Space - повляется рука , можно передвигать проект. 
Ctrl +D  дублирование. Так жэ можно совмешщать с Альт, Шифт, и потом дублировать 
i -  взять цвет.  Pick color
ctrl + shift + a - инверсивное выделение
