## Pipeline — на что уделить внимание

Модель без pipeline = демо. Production = harness.

1. **Inference** — Ollama / vLLM / свой Docker; единый OpenAI-compatible endpoint
2. **Маршрутизация** — когда локальная модель, когда облако (fallback, cost, privacy)
3. **Контекст** — RAG, индекс vault/docs, лимиты окна
4. **Tools / agents** — function calling, MCP, skills (см. Cursor-док)
5. **Проектный workflow** — git, issues, тесты, review (связка с идеей [[Zettel/Business OS/01_Бизнес_и_проекты/ИИ-инфраструктура под ключ — pipeline для проектов (идея 2026)|ИИ-инфра под ключ]])
6. **Observability** — логи запросов, latency, качество ответов
7. **Безопасность** — данные не уходят наружу, секреты, sandbox
