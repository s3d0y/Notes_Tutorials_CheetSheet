# Улучшение Обсидиан

Заметка про **плагины и приёмы Obsidian**, которые помогают вести учёбу и работу: время, слоты, доски задач. Не смешивать с бумажным планером и Bob — см. [[Продуктивность и как вести работу и задачи]].

См. также: [[Фичи и Хоткеи Обсидиан]], [[Обучение Цетелькастен и Обсидиан]].

## Сейчас (решение)

- **Визуальный канбан** отдельными плагинами — **не в фокусе**: канбан как **списки** — сырой вход в [[БЭКЛОГ ВСЕГО (BACKLOG ALL)]], операционный слой по **дням недели** в файле вида [[Zettel/Дневники/Операционная неделя W20 (11.05–17.05.2026)]].
- **Bases Kanban** — поставлен, **разбор отложен**; пригодится, если захочешь доску по полям Bases (§4 ниже).
- **Tasks** — **почитать самому**, встройку не форсить; плюс плагина на заметку: можно **закрыть задачу из интерфейса Tasks**, и он **проставит `[x]` в исходной строке** в заметке (не только «галка в сводном запросе»).

## 1. Календарь

В ядре Obsidian **нет** полноценного календаря как в Google Calendar, но есть близкие варианты (community plugins):

| Плагин | Зачем |
|--------|--------|
| **Calendar** | Боковая сетка месяца, быстрый переход к **ежедневным заметкам**. |
| **Periodic Notes** | Шаблоны дня / недели / месяца в связке с Calendar. |
| **Full Calendar** | Ближе к «настоящему» календарю: события во времени; часто есть **синхронизация с Google Calendar**. |
| **Tasks** (плагин, см. §3 ниже) | Списки по датам (`📅` / due / scheduled), запросы `task` по всему волту — удобно для **что в какой день**, не замена календаря по **часам**. |

**Смысл «календарь» в планировании дня:** не второй список задач, а **жёсткие обязательства по времени** (встречи, врачи, поездки, слоты из внешнего календаря). День = несколько выбранных задач из бэклога/эпиков **плюс** сверка с тем, что уже забито по часам.

## 2. Канбан

**Да, канбан в Obsidian делают** — обычно так:

| Подход                        | Комментарий                                                                                                             |
| ----------------------------- | ----------------------------------------------------------------------------------------------------------------------- |
| **Плагин Kanban** (community) | Классические колонки (например Backlog / Doing / Done), карточки перетаскиваются; внутри — чеклисты, ссылки на заметки. |
| **Плагин Projects**           | Доски и представления по проектам.                                                                                      |
| **Dataview / Bases**          | Доска как представление по полю «статус» в YAML — гибко, дольше настраивать.                                            |
| **Bases Kanban** (community, см. §4) | Канбан-**вид** для заметок в **Bases** (ядро Obsidian): колонки по значению поля (например статус). Репозиторий: <https://github.com/xiwcx/obsidian-bases-kanban> |
| **Canvas**                    | Визуально похоже на доску, но это **ручная** раскладка, не автоматический канбан по задачам из хранилища.               |

**Связка с твоей схемой:** эпик = полная декомпозиция; **бэклог** = только входящий поток; **неделя по дням** = зеркало «что трогаю на этой неделе». Отдельная «доска с карточками» не обязательна.

Файлы: [[БЭКЛОГ ВСЕГО (BACKLOG ALL)]] и операционная неделя (пример: [[Zettel/Дневники/Операционная неделя W20 (11.05–17.05.2026)]]).

## 3. Плагин Tasks

- Репозиторий и документация: <https://github.com/obsidian-tasks-group/obsidian-tasks>
- Назначение: собирать **чеклисты** `- [ ]` / `- [x]` из заметок с **датами, повторениями, приоритетами** и показывать их **одним запросом** (блоки кода с языком `tasks`).
- Базовая идея: задача в markdown — это строка с чекбоксом; плагин понимает эмодзи-даты (`📅` due, `⏳` scheduled и т.д. по их гайду), фильтры в запросе (`due today`, `path includes …`).
- Удобная мелочь: завершение из UI Tasks часто **сразу пишет `[x]` в файл** — не нужно вручную искать строку в эпике.
- Когда дойдёшь до настройки: **Global filter** (если нужно отделить «настоящие» задачи от прочих чекбоксов) + один пробный запрос в дневной заметке (например «всё due сегодня»).

## 4. Плагин Bases Kanban (Kanban для Bases)

**Пока не разбираемся** — см. блок «Сейчас» выше; раздел оставлен как памятка.

- Репозиторий: <https://github.com/xiwcx/obsidian-bases-kanban>
- Назначение: в режиме **Bases** (встроенная функция Obsidian для коллекций заметок с полями) добавить представление **канбан по одному полю** (колонки = значения поля, карточки = заметки).
- Зависимость: нужны **Bases** в версии Obsidian, где они доступны; плагин — только **вид**, сами базы настраиваются в UI Bases.
- Следующий шаг разобраться: README в репозитории (как добавить view «Kanban» к базе и какое поле указать как колонку).
