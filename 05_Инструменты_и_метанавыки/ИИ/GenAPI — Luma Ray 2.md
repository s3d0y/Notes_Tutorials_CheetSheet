Каталог: [[../ИИ — каталог инструментов (когда что использовать)]]

**Тип:** **российский API-агрегator** — вызов **Luma Ray 2** по HTTP (ключ, тариф за запрос).  
**Как заходить:** сайт GenAPI → API key → **curl / Python / n8n / свой скрипт**.

---

## Когда использовать

- **Автоматизация:** пакет роликов, pipeline с другими шагами
- Нужен **API**, а не клики в UI → сравни с [[Unitool — Luma]] (UI)

**Не для:** «один раз попробовать» без регистрации API — проще **Unitool** или **Kolors**.
