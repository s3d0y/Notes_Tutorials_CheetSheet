# Unitool — Luma (видео)

Каталог: [[../ИИ — каталог инструментов (когда что использовать)]]  
Ссылка: https://unitool.ai/ru/luma

**Тип:** **агрегатор** — доступ к **Luma Dream Machine** (и др.) через единый веб-UI на русском.  
**Как заходить:** **браузер** · оплата/кредиты через Unitool (не напрямую luma.ai).

---

## Когда использовать

- **Быстро попробовать** text-to-video / image-to-video **без** своего API
- Нужен **русский интерфейс** и «всё в одном» с другими моделями Unitool

**Не для:** встраивания в свой продукт (смотри [[GenAPI — Luma Ray 2]]).

---

## Luma (суть модели)

Генерация **короткого видео** из текста или картинки; качество для рекламы/соцсетей — **пробовать на кейсе**.
