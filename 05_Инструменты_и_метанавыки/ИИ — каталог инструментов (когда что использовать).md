## Через что пользоваться (логика)

| Способ | Когда |
|--------|-------|
| **Браузер (сайт сервиса)** | разовые задачи, UI, проба — **Kolors**, **Kimi**, **Unitool** |
| **API / GenAPI** | автоматизация, свой pipeline, повторяемые генерации — **GenAPI** |
| **IDE (Cursor)** | код, заметки, проекты, агент с `@файл` |
| **Подписка OpenAI / др.** | когда уже есть аккаунт и нужен «родной» продукт (**ChatGPT**, **Sora**) |

*На каждый инструмент — **отдельная страница** в `ИИ/` (ссылки, цены, первые шаги, заметки после пробы).*
