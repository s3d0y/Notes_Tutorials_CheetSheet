Дополнительный ключ `-br` или `-brief`: выводит только основную информацию в табличной форме для лучшей читабельности (только для команд `ip addr` и `ip link`)
 ![ip link, ip -br link](screenshot/3.6_ip.png)
 ```lo (loopback device) – виртуальный интерфейс, присутствующий по умолчанию в любом Linux. Он используется для отладки сетевых программ и запуска серверных приложений на локальной машине. С этим интерфейсом всегда связан адрес 127.0.0.1. У него есть dns-имя – localhost. Loopback — это термин, который обычно используется для описания методов или процедур маршрутизации электронных сигналов, цифровых потоков данных от их источника и обратно к тому же источнику без специальной обработки или модификаций.```

- получить ip адрес устройства можно командой `ip addr`. 
 ![ip addr, ip -br addr](screenshot/3.7_ip_addt.png)
 ```DCHP сервер(англ. Dynamic Host Configuration Protocol — протокол динамической настройки узла) — это сетевой протокол, позволяющий сетевым устройствам автоматически получать IP-aдрес и другие параметры, необходимые для работы в сети TCP/IP. Данный протокол работает по модели "клиент-сервер". Для автоматической конфигурации компьютер-клиент на этапе конфигурации сетевого устройства обращается к серверу DHCP и получает от него нужные параметры. Сетевой администратор может задать диапазон адресов, распределяемых сервером среди компьютеров. Это позволяет избежать ручной настройки компьютеров сети и уменьшает количество ошибок.```

- определить и вывести на экран внешний ip-адрес шлюза (ip) и внутренний ip-адрес шлюза по-умолчанию.
 ```Внешним (публичным) ip-адресом называется ip-адрес, под которым вас видят устройства в интернете, и он является уникальным во всей сети интернет. В связи с тем, что внешних адресов существует ограниченное количество, то прибегают к трансляции сетевых адресов из частных в публичные. К внутренним (частным) относятся адреса, используемые в локальных сетях. Доступ к внутреннему ip-адресу можно получить лишь в пределах локальной подсети. Как правило,  один публичный ip-адрес, предоставляемый провайдером, используется на всю локальную сеть.```  
Получить внешний ip-адрес можно оправив запрос к внешнему серверу, который предоставляет сервис определения внешнего ip-адреса. Например, сайт `2ip.ru` возвращает ip-адрес с помощью команды `curl`.  
![curl 2ip.ru: 178.23.151.201](screenshot/3.8_curl.png)

![ip r, ip route, routel: 10.0.2.2](screenshot/3.9_ip_r.png)

![cat /etc/cloud/cloud.cfg.d/subiquity-disable-cloudinit-networking.cfg](screenshot/3.10_network.png)

На Ubuntu сетевое взаимодействие контролируется функцией Netplan. Файлы конфигурации для Netplan находятся в каталоге  /etc/netplan и написаны на языке YAML. Файлы конфигурации YAML называются `50-cloud-init.yaml`, либо `00-installer-config.yaml`. В нашем случае, это `00-installer-config.yaml`. Вот его изначальное содержание:  
![cat /etc/netplan/00-installer-config.yaml](screenshot/3.11_cat_net.png)

![sudo vim /etc/netplan/00-installer-config.yaml](screenshot/3.12_cat_resolv.png)

По умолчанию используется адрес `127.0.0.53`. Чтобы проверить текущее значение, нужно прочитать файл `/etc/resolv.conf`.

![cat /etc/netplan/00-installer-config.yaml](screenshot/3.13_vim.png)

![sudo netplan apply](screenshot/3.14_sudo.png)

Чтобы воспользоваться командой `netstat` нужно установить пакет `net-tools`.
![sudo apt install net-tools](screenshot/8.6_netstat.png)
Команда `netstat` выводит на экран содержимое различных структур данных, связанных с сетью, в различных форматах в зависимости от указанных опций: состояние TCP-соединений (как входящих, так и исходящих), таблицы маршрутизации, число сетевых интерфейсов и сетевую статистику по протоколам. Вот значение некоторых ее опций:
    - Флаг `-t` – подключение по протоколу TCP;
    - Флаг `-a` – Показывать состояние всех сокетов (обычно сокеты, используемые серверными процессами, не показываются);
    - Флаг `-n` – Показывать сетевые адреса как числа.
Таким образом команда `netstat -tan` покажет состояние всех сокетов, подключенных по протоколу TCP, и все сетевые адреса отобразятся только числами.
![netstat -tan](screenshot/8.7_netstat.png)
Обозначения каждого столбца:
  - Proto – протокол, используемый сокетом. Значение этого столбца `tcp`, т.к. сейчас исследуется именно этот протокол.
  - Recv-Q – количество байтов, не скопированных пользовательской программой, подключенной к этому сокету. Значение этого столбца `0` означает либо хорошую работу программы (вовремя читает все данные с порта), либо отсутствие вызовов.
  - Send-Q – количество байтов, не подтвержденных удаленным хостом. Значение этого столбца `0` означает либо удаленный сервер прочитал все, что на него отправили, либо отсутствие вызовов.
  - Local Address – ip-адрес локального компьютера и номер используемого порта. Значение `0.0.0.0:2022` означает, что у порта 2022 адрес 0.0.0.0.
  - Foreign Address – ip-адрес и номер порта удаленного компьютера, к которому подключен сокет. Значение `0.0.0.0:*`, означает, что  у удаленного порта адрес 0.0.0.0, а порт еще не установлен.
  - State – состояние сокета. Значение `LISTEN` означает, что cокет прослушивает входящие соединения.  
  `0.0.0.0`, - не маршрутизируемый адрес, который получают устройства, когда они не подключены к какой-либо сети TCP/IP. Устройство может получить этот адрес по умолчанию, если оно не в сети. В случае сбоев назначения адреса, он может быть автоматически назначен DHCP.

## <a id="part15">Part 15. Использование планировщика заданий CRON</a>
> Задание:  
> - Используя планировщик заданий, запусти команду uptime через каждые 2 минуты.
>   - Найди в системных журналах строчки (минимум две в заданном временном диапазоне) о выполнении.
>   - Выведи на экран список текущих заданий для CRON. Вставь в отчёт скрины со строчками о выполнении и списком текущих задач.
> - Удали все задания из планировщика заданий. В отчёт вставь скрин со списком текущих заданий для CRON.

- `Cron` — это хронологический демон-планировщик задач. Команда `crontab` создает файл `crontab`, содержащий команды и инструкции для запуска демона `cron`. Каждая запись в `crontab` состоит из шести полей, указываемых в следующем порядке: `minute hour day month weekday command`. Поля разделяются пробелами или знаками табуляции. Первые пять представляют собой числовые значения, а шестое - это команда, которая будет выполняться.  
Кроме числовых значений, могут встречаться специальные символы: 
    - `*`: подстановочный символ, который представляет все значения
    - `,`: список значений
    - `-`: диапазон значений, между которыми запускается через 1
    - `*/`: шаг повторения

- Команда для редактирования файла расписания для текущего пользователя: `crontab –e` (после первого запуска она предложит выбрать текстовый редактор, после чего всегда им будет открывать им для редактирования файл `crontab`):
![*/2 * * * * uptime](screenshot/15.1_cron.png)
Запись `*/2 * * * * uptime` будет запускать `uptime` каждые 2 минуты.

- Запись о выполнении можно увидеть `/var/log/syslog`:
![sudo grep uptime /var/log/syslog](screenshot/15.2_grep.png)

- Текущие задачи `cron` можно увидеть командой `crontab –l`:
![crontab –l](screenshot/15.3_cron_l.png)

- Удалить все задачи из `cron` можно снова с помощью `crontab –e`. После чего проверим, с помощью `crontab –l`, что все задачи удалены:
![crontab –l](screenshot/15.4_cron.png)
![crontab –l](screenshot/15.5_del_cron.png)
